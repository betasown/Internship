## 📜 Description of Files

### 🔖 `Scripts/bookmarks.json`
This file contains saved company bookmarks for quick access.

**Example links:**
- Mail in Black
- SharePoint (internal)

---

### ⚡ `Scripts/script_raccourcis.ps1`
A PowerShell script that:
- Creates desktop shortcuts to important company tools.
- Downloads custom icons for each shortcut.

**Why use it?**
Quickly set up a work environment with essential tools.

---

### 🖼️ `Scripts/script_wallpaper.ps1`
A PowerShell script that:
- Downloads a wallpaper from an online source.
- Sets it as the desktop and lockscreen background.
- Updates Windows registry values to apply the change.

---

### 🖌️ `images/Wallpaper.png`
This is the default wallpaper used in the script above. It is stored online in this repository.
